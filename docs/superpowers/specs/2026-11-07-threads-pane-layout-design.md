# Threads: выбор треда и ширина панелей

## Цель

При входе в Threads на широком экране сразу показывать первый тред справа, оставляя его непрочитанным до клика по карточке. Дать переписке больше места и разрешить менять ширину перетаскиванием или клавиатурой.

## Подходы

- Выбран: правая панель занимает по умолчанию 60% доступной области; разделитель позволяет каждой из двух панелей занимать 40–60% этой области. На пороге 800 px обе панели сохраняют минимум 320 px. Использовать существующий `ResizablePaneDivider`.
- Отклонён: новая фиксированная ширина с тем же разделителем. При изменении ширины окна она даёт менее устойчивое соотношение панелей.

## Поведение

- После загрузки списка на ширине от `AppBreakpoints.sideThread` первый тред выделен и полностью отображается справа. Автоматический показ не вызывает `markRead`.
- Явный клик по любой карточке, включая уже показанную первую, отмечает её прочитанной по текущим правилам `ThreadPane`. При обновлении списка выбранный тред сохраняется, если он ещё есть; если исчез, отображается новый первый без отметки о прочтении.
- Кнопка закрытия скрывает правую панель до следующего клика по карточке. При следующем входе в Threads начальный выбор выполняется снова.
- На узкой ширине список остаётся самостоятельным экраном; клик открывает маршрут треда. Автоматический выбор не открывает маршрут.
- Ширина после перетаскивания живёт только в состоянии экрана и ограничивается при изменении размеров окна. Другие экраны с `ThreadPane` не меняются.

## Проверка

Widget тесты: начальный показ без `markRead`, клик по уже показанному первому треду, выбор и исчезновение другого треда, границы ширины и перетаскивание, ширины по обе стороны `sideThread`, крупный текст. Форматирование и `flutter analyze`.
